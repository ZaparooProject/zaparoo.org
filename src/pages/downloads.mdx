  | Architecture | Common devices |
  |--------------|----------------|
  | **x86-64** | Steam Deck, ROG Ally, Legion Go, most Windows PCs and laptops, Intel Macs |
  | **ARM64** | Raspberry Pi 4/5, Zero 2, handheld emulators, Apple Silicon Macs |
  | **ARM32** | Raspberry Pi 3, Zero, older handhelds |
  | **x86** | Legacy PCs (rarely needed) |
