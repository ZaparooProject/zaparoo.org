# Help

Stuck? The fastest way to get help is the [Discord](https://zaparoo.org/discord). Search the docs first if you can, and include a [log file](#collect-a-log-file) when reporting a bug.

## Where to ask

- **[Discord](https://zaparoo.org/discord)**: quickest way to get help from the community and the developers
- **[Subreddit](https://reddit.com/r/Zaparoo)**: if you prefer Reddit
- **[GitHub Issues](https://github.com/ZaparooProject/zaparoo-core/issues)**: bug reports and feature requests
- **[Documentation](/docs/)**: guides and reference
  - [Common tasks](/docs/common-tasks/) for the page that answers what you want to do
  - [Platforms](/docs/platforms/) for installation guides
  - [Readers](/docs/readers/) for hardware setup and troubleshooting
  - [ZapScript](/docs/zapscript/) for commands and syntax
  - [Config](/docs/core/config/) for every configuration option

## Collect a log file

### Zaparoo App

1. Go to **Settings > Advanced > View logs**
2. Tap one of:
   - **Download** (<Download size={16} />) to save the log file
   - **Upload logs** (<Upload size={16} />) to send it to *logs.zaparoo.org* and get a shareable link

### Terminal UI

1. Go to **Settings > Logs**
2. Select one of:
   - **Copy** to save the log file
   - **Upload** to send it to *logs.zaparoo.org* and get a shareable link

:::warning MiSTer only
The Zaparoo log file on MiSTer is deleted every time the system is powered off. Collect logs after the problem happens and before turning off the MiSTer.
:::

## What to include in a report

Include enough context for someone else to reproduce and diagnose the problem:

1. Your platform and device model
2. Zaparoo Core, App, or Frontend versions
3. Your reader model or a link to its product listing
4. The exact token contents, including any ZapScript, when relevant
5. Steps to reproduce the problem
6. What you expected to happen and what actually happened
7. A log captured immediately after reproducing the problem

## Error reporting

Zaparoo Core has built-in error reporting powered by [Sentry](https://sentry.io), and the Zaparoo App uses [Rollbar](https://rollbar.com). Reports are anonymized and contain no personal information. Core's reporting is off by default for privacy; turning it on helps find and fix bugs faster.

To enable error reporting in Core:

1. Open the Zaparoo App or terminal UI
2. Go to **Settings > Advanced**
3. Turn on **Error reporting**

## Debug logging

Debug logging captures more detail than standard logs. It is off by default because it makes logs noisy.

1. Open the Zaparoo App or terminal UI
2. Go to **Settings > Advanced**
3. Turn on **Debug logging**
4. Reproduce the problem
5. Collect the logs as described above

:::tip
All of these settings can also be set directly in the [config file](/docs/core/config/).
:::
