# Features

Everything in this section is optional. Zaparoo launches games out of the box; these features are the things you can turn on or configure when you want more. If you are new, start with [device backups](./backups.md) and [playlists](./playlists.md).

## Everyday

- [Device Backups](./backups.md): save and restore your settings and user data, locally for free or automatically off-site with Warp
- [Playlists](./playlists.md): put a folder or a list of games on one card and step through it with repeated scans
- [Audio Playback](./audio.md): play music and sound files through Core, including background music while you game
- [Play Controls](./play-controls.md): hold disruptive scans for confirmation and enforce playtime limits
- [Device Profiles](./profiles.md): give each person their own settings, limits, and (on MiSTer) saves

## Matching and metadata

- [Mappings](./mappings.md): assign ZapScript to tokens that can't be written, such as Amiibo, barcodes, and discs
- [Tags](./tags.md): labels pulled from filenames (region, disc number, and more) used to filter and match games
- [Media Database and Scraping](./scraping.md): index launchable media, then import local artwork and metadata
- [Systems](./systems.md): reference of every system ID used in configuration and ZapScript

## Automation and integration

- [Hooks](./hooks.md): run ZapScript when a token is scanned, media starts or exits, or Core becomes ready
- [Launchers](./launchers.md): how Core starts games on each platform, plus custom launchers and launcher controls
- [Publishers](./publishers.md): send Core events to MQTT brokers or PixelCade LED displays

Looking for something specific? The [common tasks](../common-tasks.md) page links straight to the answer.
