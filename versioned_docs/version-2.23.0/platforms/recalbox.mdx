# Recalbox

:::danger[Experimental]
Recalbox support is experimental and not listed as a [supported platform](./index.mdx#support-levels) yet. Expect missing features and rough edges.
:::

Zaparoo Core on [Recalbox](https://www.recalbox.com/) launches games through Recalbox's EmulationStation. Release builds are available for x86-64, ARM, and ARM64 devices.

## Install

Enable SSH in Recalbox settings (**Network > SSH Server**). The default login is `root` / `recalboxroot`. Connect to the device over SSH, then run:

```bash
curl -fsSL https://zaparoo.org/install.sh | sh
```

The installer copies Core to `/recalbox/share/system/zaparoo/zaparoo` and adds a Recalbox user script that starts it on boot and restarts it if it stops. Recalbox cannot run programs from the share, so the script runs a copy at `/tmp/zaparoo-bin/zaparoo-start`. Use that path to run Core commands over SSH.

Once Core is running, write your first token from the [Zaparoo App](/docs/app/#first-run) or the built-in web UI at `http://<device-ip>:7497/app/`.

## Uninstall

```bash
/tmp/zaparoo-bin/zaparoo-start -uninstall
```

This stops Core and removes the user script. Delete `/recalbox/share/system/zaparoo` if you also want to remove your settings and data.

| Mappings directory | `/recalbox/share/system/zaparoo/mappings` |

## Client security

Recalbox requires remote clients to pair. Pair the Zaparoo App, a browser, or another client with the six-digit PIN Core shows when you run `/tmp/zaparoo-bin/zaparoo-start -pair`. The PIN expires after five minutes. See [encryption](../core/config/service.md#encryption) for how paired clients and their permissions work.

## Launchers

Core adds a launcher for each system in Recalbox's system list, and indexes games from `/recalbox/share/roms`, the built-in ROMs, and the `recalbox/roms` folder, `roms` folder, or root of each USB drive. Games launch through EmulationStation, so a game has to be in one of EmulationStation's ROM folders. Games started from EmulationStation also show as playing in Zaparoo.

The RomM launcher downloads games from a RomM server. See [Media Servers](../features/media-servers.md).

Stopping a game is the only [launcher control](../features/launchers.md#launcher-controls) available.

[Input commands](../zapscript/input.md) are accepted but nothing is typed.

Shell scripts can also be launched. Add them to the [`allow_file`](../core/config/launchers.md#allow_file) list in `config.toml`.
