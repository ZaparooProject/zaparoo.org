# Zaparoo Frontend

<img className="docHeroImage" src="/img/showcase/BigBlue709_crt_setup.webp" alt="Zaparoo Frontend displaying a Genesis library on a CRT television" width="100%" loading="lazy" />

*Zaparoo Frontend running as part of BigBlue709's CRT setup in [Community Showcase #6](/blog/community-showcase-6).*

Zaparoo Frontend is a TV and controller-friendly interface for browsing and launching your [Zaparoo Core](../core/index.md) media library on [MiSTer FPGA](../platforms/mister/index.md).

Frontend is optional. It runs on the MiSTer display and uses Core for media scanning, launching, metadata, favorites, and token writing. You can continue using physical tokens, the [Zaparoo App](../app/index.md), the [Web UI](../app/web.md), or the [TUI](../core/tui.md) with or without Frontend.

## How Frontend works

Frontend displays the library managed by Core. Core finds games during a media database update, imports local artwork and metadata during a scrape, and launches the selected game. Frontend provides the on-screen library, menus, and controller interface for those actions.

Frontend does not download artwork from the internet. Start with [Add Artwork and Metadata](./scraping.mdx) if you want covers, screenshots, descriptions, or other game information in the browser.

## Quick start

1. [Install or update Frontend](./setup.mdx) on MiSTer.
2. Start Frontend and run the first media database update when prompted.
3. [Add artwork and metadata](./scraping.mdx) if you want game covers and descriptions.
4. [Browse and launch games](./browsing.mdx) from the library hub.

For platform-specific launcher behavior, see the [MiSTer launcher documentation](../platforms/mister/launchers.md).
