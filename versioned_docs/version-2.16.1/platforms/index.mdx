# Platforms

Zaparoo Core runs directly on the stable and beta platforms below. If you're not sure where to start, the [getting started guide](/start/) can build a setup around hardware you already use.

Support labels describe Zaparoo Core integration, not the maturity of the platform itself:

- **Stable:** Core installs and launches supported media on the platform
- **Beta:** Core installs, but some setup paths and launchers remain incomplete
- **Community integration:** uses Zaparoo tokens without running Core directly
