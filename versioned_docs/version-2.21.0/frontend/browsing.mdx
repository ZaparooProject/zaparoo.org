# Browse and Launch Games

Frontend starts at your library hub. From there you can browse categories, systems, games, favorites, recents, and folders. Games launch through [Zaparoo Core](../core/index.md), so launcher configuration and media paths follow your normal Zaparoo setup.

If covers, screenshots, or descriptions are missing, follow [Add Artwork and Metadata](./scraping.mdx) before changing the browsing options.

## Browse the library

Open a category to browse its systems, then select a system to browse its games. Opening a system starts at its root folder. While browsing games, open the **View** menu and choose **Go to...** to jump by letter or bucket, **Random game** to pick one for you, [**Search here...**](#search) to search the current system or folder, or [**Tags**](#filter-games) to narrow the list. In list layout, Left and Right move a whole page.

Hold a direction to move faster through a long list. Frontend advances from rows to pages, then letters, with a rail showing your position.

A folder that holds the discs of one game appears as a single row. Selecting it launches the disc you played last. To pick another, open its options menu and select **Choose disc**.

The **Other** category holds [launchable items](../features/launchers.md#launchables) that have no normal game file behind them, such as ROM-less MiSTer cores. You can launch them like any other game or write them to a token.

## Search

Select the **Search** tile on the Hub. Type part of a name on the on-screen keyboard, or on a connected keyboard, and matching games appear in the card beside it as you type. Set **System** to search one system instead of all of them, and **Tags** to narrow the results the same way as [filtering a system](#filter-games). Before you type, the card lists your recent searches.

On the Search screen the controller buttons edit the text from wherever the cursor is:

| Button | Action |
| ------ | ------ |
| Confirm | Press the highlighted key. Hold to repeat. |
| View | Delete a character. Hold to clear the name. |
| Options | Type a space. |
| L and R | Move the text cursor. |

Select **Search** on the keyboard to open the results as a game list sorted by name. Back returns to your search.

To search inside one system or folder, open the **View** menu while browsing it and choose **Search here...**.

To keep a search, open the **View** menu on the results and choose **Add to Hub**. The new tile opens those results directly. See [saved searches](./customization.mdx#saved-searches) to write one by hand, including searches across several systems.

## Filter games

While browsing a system, open the **View** menu and select **Tags**. Choose one value per category, such as **Genre**, **Year**, **Players**, or **Region**. Each choice applies as you make it. **Collections** filters by favorites, liked games, games saved for later, or one of your [decks](../online/index.md#cards-and-decks). Available choices come from the system's tags and metadata.

Selected categories must all match. Choose **Any** to clear one category, or **Clear tags** to remove them all. Filters are remembered separately for each system and apply to games directly inside the current folder; subfolders remain visible.

## Hide games

To keep a game or folder out of normal browsing, open its options menu and choose **Manage game > Hide** for a game, or **Hide** for a folder. Hiding a folder also takes its games out of search, system counts, and random picks. Visibility is saved in Core, and hiding does not delete any files.

To undo it, turn on **Settings > Library > Browsing > Show hidden items**, then choose **Unhide** from the same place. Favorites, Recently played, and **Collections** filters still include hidden games that belong to those views.

## Arrange the Hub

The Hub is a grid you arrange yourself. Tiles can be categories, the built-in **Resume**, **Favorites**, **Recently played**, **Search**, **Update**, and **Settings** actions, systems, folders, games, or [saved searches](#search). To add a tile, choose **Add to Hub** from the options menu of a folder or from [**Manage**](#use-the-options-menu) in the options menu of a system or game, or use **Add item...** in the Hub's **View** menu; a folder that holds a single game is added as that game. A tile's options menu offers **Move** and **Hide** for categories and actions. A tile you added for a game or system shows that item's own menu, with **Move tile** and **Remove from Hub** under **Manage**. **Reset layout** in the View menu restores the default arrangement. The layout is stored under `[[hub.items]]` in `frontend.toml`; see [configuration file](./customization.mdx#configuration-file).

## Use the options menu

The options menu holds the actions for the item you have selected. The same game shows the same menu in a system, Favorites, Recently played, Search results, and on the Hub.

On a game:

- **Details**, and **Add to favorites**.
- **Choose disc** for a multi-disc game.
- **Write to token**. With an NFC reader connected, choose **Write to NFC token** or **Write with App**. Without one, it shows a code to scan with the Zaparoo App.
- **Discover alt. versions** for Arcade games.
- **Manage game**, which opens **Change launcher**, **Add to Hub**, [**Hide**](#hide-games), and **Update metadata**.

On a system:

- **Launch system** to boot its core with no game loaded.
- **Random game**.
- **Manage system**, which opens **Change launcher**, **Add to Hub**, **Hide**, **Update media database**, and **Update metadata**.

A folder has **Add to Hub** and **Hide**. A category tile on the Hub has **Move**, **Hide**, and **Manage category** for updating the media database or metadata of its systems.

![Options menu on a game, with Details, Add to favorites, Change launcher, Write with App, Add to Hub, and Update metadata](/img/docs/frontend/game-options-menu.webp)

See [Add Artwork and Metadata](./scraping.mdx#understand-the-library-actions) for the difference between updating the media database and updating metadata.

## Favorites

Favorites live on the Hub. To browse favorites within one system, use [**View > Tags > Collections**](#filter-games). In the favorites view, the **View** menu can **Sort** by default order or A-Z, **Group by** system, or pick a **Random favorite**. Favorite systems have their own screen as well.

## Choose alternate MiSTer launchers

Open a system's options menu and choose **Manage system > Change launcher** to pick a launcher that Core supports for that system. Launchers Core reports as unavailable appear dimmed, with a reason when one is available. They remain selectable. Alternate launchers include RetroAchievements, DB9, LLAPI, PWM, 80 MHz overclock, DualRAM, and Sinden variants. Depending on the system, you might see options such as `DualRAMPSX`, `DB9SNES`, `LLAPINintendo64`, `SindenPSX`, or `RASNES`. **Manage game > Change launcher** overrides the launcher for one game.

RetroAchievements launchers also support a group preference. If you generally want a RetroAchievements core whenever one is installed, set this preference in Core's `config.toml`:

```toml
[launchers]
preference = ["RetroAchievements"]
```

Core then prefers an available RetroAchievements launcher and falls back to the normal launcher when no supported RetroAchievements core is installed for that system. Explicit token launchers and saved system or game overrides still take priority. See the [MiSTer alternate launcher reference](../platforms/mister/alternate-launchers.md) for the full launcher list and configuration details.

## Change browsing options

Open **Settings > Library > Browsing** to change how the library appears:

- **Systems layout** and **Games layout**: a grid of covers or a detailed list. The games layout also covers Favorites and Recents.
- **Preferred artwork**: which imported image type Frontend asks Core for first.
- **Show hidden items**: shows hidden systems and games so you can unhide them.
- **Show original filenames**: each file's real name, without the extension, instead of Core's cleaned-up title.

Related settings live elsewhere: system logo style and **Reduce motion** under **Settings > Appearance**, regional system names (**Region**) and **Clock format** under **Settings > Language**, and **Mouse support** under **Settings > Controls**.

When multiple games have the same display name, Frontend can show variant tags inline to help distinguish regions, versions, and other variants.

For custom system artwork, Hub icons, and display names, see [Customize Frontend](./customization.mdx).

## Controls

The default keyboard controls are:

| Action | Default keys |
| ------ | ------------ |
| Move | Arrow keys |
| Select | `Enter` |
| Back | `Escape` or `Backspace` |
| Options menu | `Tab` |
| View menu | `Space` |
| Previous page | `PageUp` |
| Next page | `PageDown` |

MiSTer automatically maps your controller buttons to these keys: A selects, B goes back, X opens the options menu, Y opens the View menu, L and R change page, Select goes back, and Start opens help. You can swap the confirm and cancel buttons, or the options and view buttons, under **Settings > Controls**, and change the on-screen button icons with **Button style**.

Keyboard bindings can be changed in `/media/fat/zaparoo/frontend.toml` under `[input.keyboard]`; a list you provide replaces the default for that action.
