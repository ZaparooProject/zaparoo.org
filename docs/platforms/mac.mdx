# macOS

:::danger[Experimental]
macOS builds are experimental and not listed as a [supported platform](./index.mdx#support-levels) yet. Expect missing features.
:::

Zaparoo Core on macOS supports shell script launching. Full launcher support is coming in a future release.

## Install

Download Zaparoo Core for macOS from the [Downloads page](/downloads/), unzip it and copy the `zaparoo` file to `/usr/local/bin`.

```bash
cd /usr/local/bin
./zaparoo -install
launchctl load ~/Library/LaunchAgents/org.zaparoo.core.plist
```

## Uninstall

```bash
./zaparoo -uninstall
```

## File paths

| Item               | Path                                             |
| ------------------ | ------------------------------------------------ |
| Config file        | `~/Library/Application Support/zaparoo/config.toml` |
| Data directory     | `~/Library/Application Support/zaparoo`          |
| Log file           | `~/Library/Application Support/zaparoo/logs/core.log` |
| Mappings directory | `~/Library/Application Support/zaparoo/mappings` |

Where `~` is the home directory of the current user.

## Launchers

| Launcher      | Notes                        |
| ------------- | ---------------------------- |
| Shell Scripts | Custom `.sh` file execution  |

Create shell scripts to launch games, applications, or media. Add scripts to the `allow_file` list in config.toml and restart Zaparoo.
